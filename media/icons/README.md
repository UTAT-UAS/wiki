# Icons

The SVGs in this directory are [Material Symbols](https://fonts.google.com/icons)
(Outlined, 24 px) by Google, from
[google/material-design-icons](https://github.com/google/material-design-icons)
at commit `10ecc1479061`. They are licensed under the Apache License 2.0; see
[`LICENSE`](LICENSE). The files are unmodified copies of
`symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg`.

`media/build_comm_diagrams.py` embeds them in the communication link diagrams
and recolours them to match the page theme.

| Icon | Used for |
| --- | --- |
| `memory` | Flight controller (PX4) |
| `developer_board` | Jetson Orin Nano |
| `sports_esports` | RC transmitter |
| `laptop_windows` | GCS laptop, QGroundControl |
| `router` | RFD900x telemetry radios |
| `cell_tower` | 4G LTE modem |
| `vpn_lock` | Tailnet (Tailscale) |
| `videocam` | FPV camera and VTX |
| `connected_tv` | FPV monitor |
| `settings_input_hdmi` | Capture card |
| `photo_camera` | Depth camera, Gazebo camera |
| `settings_input_antenna` | ELRS receiver |
| `desktop_windows` | Gazebo GUI |
| `view_in_ar` | Gazebo |
| `terminal` | PX4 SITL |
| `web` | Browser |
| `hub` | ROS 2 graph |

`media/drone.svg` is not part of this set.
